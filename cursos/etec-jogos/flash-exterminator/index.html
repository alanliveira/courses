Sobre o projeto

Flash Exterminator é um jogo espacial criado em Adobe Flash e executado no navegador pelo emulador Ruffle. Ele foi desenvolvido como projeto da disciplina Desenvolvimento de Jogos para Web I, do curso técnico em Jogos Digitais no ano de 2016.

Como jogar

  • Use as setas para movimentar a nave.
  • Pressione a barra de espaço para atirar.
  • Clique dentro da tela uma vez para ativar o áudio e dar foco aos controles.

Modos de jogo

  • Monitor: jogue na visualização padrão, com controles pelo teclado.
  • Game Boy: abra o modo portátil para jogar com direcional e botão A na tela.
  • Use START ou B para voltar ao modo Monitor.
