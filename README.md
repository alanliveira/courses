# 🌑 Shadow Trails

> Um mistério sombrio está tomando conta do pacato vilarejo de Little Rock.

**Shadow Trails** é um jogo desenvolvido pela **Precioso Studio** como projeto acadêmico do curso de **Jogos Digitais da FATEC Carapicuíba**.

O jogador acompanha **Naian**, o herói do vilarejo, enquanto investiga acontecimentos misteriosos que ameaçam a tranquilidade de Little Rock. Ao seu lado está **Lohan**, seu leal lobo de estimação.

O principal antagonista é **Shannon, o Imperador Vulcanicus**, uma figura sombria que busca ativar o vulcão para obter mais energia e possui o poder de transformar criaturas em seres de fogo.

## 🎮 Sobre o projeto

O jogo combina diferentes elementos de gameplay, incluindo:

* 🗺️ Exploração
* 💬 Sistema de diálogos
* ⚔️ Batalhas
* 🧩 Puzzles
* 🚶 Movimentação e interação
* 👾 NPCs e inimigos
* 🎵 Música e efeitos sonoros
* 🖥️ Interface e menus

O projeto possui diferentes ambientes, incluindo a **praça da cidade, moradias e uma mansão**, além de diversos personagens que participam da história.
