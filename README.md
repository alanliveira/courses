### Como clonar um repositório interno

```bash
# história completa (todos os commits do monorepo)
git clone git@github.com:alanliveira/courses.git

# apenas os arquivos de um curso, com o histórico daquele repo
git clone --filter=blob:none --sparse git@github.com:alanliveira/courses.git
cd courses
git sparse-checkout set cursos/<subcategoria>/<repositório>
```

### Histórico de um repositório específico

```bash
git log --oneline cursos/<subcategoria>/<repositório>
```
